PRATHAM STORE — Premium Web Gaming Platform
=============================================
Designed & Developed by: Pratham Sinha

Description:
Pratham Store is a high-performance, modern gaming portal featuring 145+ curated
web games. Designed with a cyber-luxe dark/light aesthetic, instant live search,
Web Audio SFX, responsive bento grids, favorites/history tracking, and built-in
interactive offline arcade mini-games.

Features:
- 145+ Curated Games across Racing, Action, Puzzle, Sports, .io, Adventure & Casual
- Instant Live Search with auto-complete and keyboard shortcut (/)
- Dynamic Hero Showcase with auto-cycling featured games
- Smooth Category filtering & multiple view layouts (Standard & Cozy)
- Favorites & Recently Played history stored locally via LocalStorage
- Interactive Game Player modal with ratings, controls guide, and direct play
- Built-in Instant Offline Games:
  * Tic-Tac-Toe Ultimate (Minimax AI & 2-Player mode)
  * 2048 Neon Edition
  * Cyber Runner 3D (Endless Canvas runner)
- Gamer Avatar Studio & Profile customizer
- Synthesized Web Audio sound effects (with mute toggle)
- Full Dark / Light mode toggle
- 100% Offline-friendly with zero external runtime blocking dependencies

Files:
- index.html: Main application entry point
- package/index.html & homepage.html: Package mirror entry points
- assets/style.css: Comprehensive responsive styling & themes
- assets/app.js: Application logic, state management & arcade mini-games
- assets/games-data.js: Catalog database of 145 games
- assets/thumbnails/: 145 optimized offline webp thumbnails
- manifest.json: Web app manifest
